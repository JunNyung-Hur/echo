# echo v0.0.3

A major agent upgrade for **echo** — the chat agent now edits your notes surgically instead of rewriting them, shows its work as live step cards, and notes move to clean Markdown with selectable styles. Builds on v0.0.2.

## What's new

- **A rebuilt chat agent (talker = doer)** — the agent now reads your note and applies **precise in-place edits** instead of regenerating the whole body. Every edit shows up as a step card in chat; expand it to see a red/green diff of exactly what changed. Fixing one word no longer risks the rest of your note.
- **The agent asks before it guesses** — when a choice is genuinely ambiguous (or destructive, like re-transcribing), the agent stops and asks with **choice buttons** right in the chat. Pick one, or type your own answer.
- **Live progress cards** — while the agent works you see each step as it happens: reading the note, editing, transcribing each attached recording, writing the note. No more opaque spinner.
- **Markdown notes + note styles** — note bodies are now clean Markdown. Freeform notes get a **note style**: Minimal, Notepad, Report, or Colorful — switch per note from the body header, set the default in **Settings → Note style** (live thumbnails), and pick your favorite during first-run setup. Minutes notes keep a fixed, tidy look.
- **Safer note writing** — new guards protect your content: a whole-note rewrite that would lose your content is rejected, mismatched edits are retried automatically, and a runaway AI response is cut off instead of hanging forever.
- **Model settings** — set a max output token limit and a **Disable thinking** toggle per LLM endpoint (for Qwen-family local servers via llama.cpp / vLLM).
- **Quieter by default** — completion notifications (transcription / note ready) are now **off by default**; turn them on in Settings → Notifications.

## Install (Windows x64)

1. Download **`echo_0.0.3_x64-setup.exe`** below and run it.
2. **ffmpeg is bundled** — nothing else to install for audio. WebView2 is installed automatically if it's missing (Windows 11 already has it).
3. First-run setup walks you through language, AI models, and your default note style. Register an OpenAI-compatible **LLM** endpoint (required) and an **ASR** endpoint (optional but needed for recording). A cloud API key or a local server (vLLM, llama.cpp, Ollama) all work.

See the [user guide](../user-guide.md) for a full walkthrough.

## Requirements

- Windows x64. (It runs on Windows 11 ARM via x64 emulation, but ARM is not a build target.)
- An OpenAI-compatible ASR endpoint and LLM endpoint that you provide.

## Notes & limitations

- Single-user by design — no accounts, no sync. Your data lives in a local SQLite database in your app-data folder.
- API keys are stored locally in plaintext in this version.
- Full-text search over note bodies isn't included yet (search covers titles, memos, locations, and tags).
- macOS / Linux builds aren't published in this release.
- Upgrading from v0.0.2: existing notes (HTML era) keep rendering and stay editable; notes created from v0.0.3 use Markdown. Chat messages from before v0.0.3 keep their old plain-text look.

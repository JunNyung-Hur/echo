# echo v0.0.4

**Status: in preparation.** This version collects the source-grounded note and transcription reliability changes merged in [PR #1](https://github.com/JunNyung-Hur/echo/pull/1), and refreshes the documentation and version metadata. An installer has not been published as part of this preparation.

## Changes

- The chat agent can search completed transcripts belonging to the current note and read bounded source passages, including text beyond the UI preview.
- Freeform attachments feed original evidence into the conversation editor. Short sources are passed directly; long sources can be read through source tools. The former nested note-writing and intermediate-summary flow is removed.
- New freeform content is inserted without rewriting the existing text. Existing-content edits use the note version read by the agent; stale edits are rejected before replacing the active version.
- Failed audio chunks block transcription completion and downstream note generation. Successful chunk results are cached; retries reuse them when the recording and ASR configuration match, while preserving existing notes.
- Stream decoding preserves Korean and emoji across network boundaries. Malformed tool arguments and truncated model responses are rejected; incomplete tool calls are not executed.
- Note-writing instructions retain conditions, corrections, attribution, and unresolved questions, with a structure appropriate to the source.
- English and Korean READMEs now explain setup, source-based questions, recovery, data handling, and verification. App, installer, and npm package version metadata are aligned at `0.0.4`.

## Compatibility and upgrading

- The app identifier remains `com.echo.app`; this version introduces no database migration or new storage location.
- Existing Markdown notes and version history remain in place. Legacy HTML notes can still be read and edited; adding new freeform content may require conversion through the existing read/edit flow.
- Resuming a failed task reuses eligible cached transcription results. Explicit full re-transcription remains a separate operation; review its confirmation before replacing prior work.
- Use an LLM with Chat Completions and tool calling, and an ASR endpoint compatible with the selected request mode. Models and credentials are supplied by the user.
